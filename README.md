# More or Less — Save the Princess

A 60-second trivia rescue game. Two facts, one question: is it **more or less**?
Answer 7 of 10 right to pull the princess out of the lava before the monster gets her.

**Play free:** https://truonglvpems.github.io/more-or-less/

- Daily puzzle: everyone gets the same 10 questions each day, share your result
- Endless mode with friend challenges by link
- Facts from public sources (World Bank, CIA World Factbook, Box Office Mojo, Britannica)
